# 스레드 자동 게시 설정 (한 번만)

비용은 들지 않아요. 30분 정도 걸려요.
Meta 화면 메뉴 이름은 자주 바뀌어요. 아래 이름과 조금 달라도 비슷한 메뉴를 찾으면 돼요.

## 1. Meta 개발자 계정 만들기
1. https://developers.facebook.com 에 들어가 페이스북 계정으로 로그인해요.
2. 오른쪽 위 **시작하기** → 휴대폰 인증 → 개발자 등록을 마쳐요.

## 2. 앱 만들기
1. **내 앱 → 앱 만들기**를 눌러요.
2. 사용 사례에서 **Threads API 액세스**를 골라요.
3. 앱 이름은 `오늘의 할인 게시`처럼 아무 이름이나 넣고 만들어요.

## 3. 권한 켜기
1. 앱 대시보드 → **사용 사례 → Threads API 액세스 → 사용자 지정(설정)**으로 들어가요.
2. 권한에서 아래 세 개를 **추가**해요.
   - `threads_basic`
   - `threads_content_publish` (글 올리기)
   - `threads_manage_replies` (링크 첫 댓글 달기)

## 4. 내 스레드 계정을 테스터로 넣기
1. 앱 대시보드 → **앱 역할 → 역할 → 사람 추가** → **Threads 테스터**를 고르고 **오늘의 할인** 스레드 아이디를 넣어요.
2. 스레드 앱이나 웹(threads.com)에서 **설정 → 계정 → 웹사이트 권한 → 초대**로 가서 초대를 **수락**해요.

앱 심사는 필요 없어요. 내 계정에만 올리는 앱은 개발 모드 그대로 쓰면 돼요.

## 5. 토큰 받아서 GitHub에 넣기
1. **사용 사례 → Threads API 액세스 → 설정** 화면 아래쪽의 **사용자 토큰 생성기(User Token Generator)**에서 내 계정 옆 **액세스 토큰 생성**을 눌러요.
2. 로그인하고 권한을 허용하면 긴 글자(토큰)가 나와요. 복사해요.
   - 이 토큰은 비밀번호와 같아요. 채팅이나 이슈에 붙여 넣지 마세요.
3. https://github.com/choiyh040-bit/link/settings/secrets/actions 로 가서 **New repository secret**을 눌러요.
   - Name: `THREADS_ACCESS_TOKEN`
   - Secret: 복사한 토큰
   - **Add secret**

## 6. 점검하기
1. https://github.com/choiyh040-bit/link/issues/new 에서 제목에 `점검`이라고만 쓰고 **Create**를 눌러요.
2. 1~2분 뒤 그 이슈에 `✅ 토큰 정상: @계정이름` 댓글이 달리면 끝이에요.
   - 결과는 **Actions** 탭에서도 볼 수 있어요.

## 매일 쓰는 법 (공유 문구만 붙이면 끝)
1. 토스 앱 쉐어링크에서 올릴 상품마다 **공유 → 문구 복사**를 해요.
2. https://github.com/choiyh040-bit/link/issues/new 에서
   - 제목: `상품` (아무 말이나 뒤에 붙여도 돼요. 예: `상품 10/24`)
   - 본문: 복사한 공유 문구를 붙이고, **링크 바로 아래 줄에 `할인가/정가`** 를 적어요. 여러 상품을 이어서 붙여도 돼요.
     ```
     ✱ 이 포스팅은 토스쇼핑 쉐어링크 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
     양계장사람들 무항생제 계란, 대란, 60구, 1개
     https://toss.shopping/_m/D54kVLUt
     15900/26900
     ```
     토스 앱에 정가 없이 할인율만 보이면 `5350/70%`처럼 적어요. 할인이 없으면 `15900`만 적어요. (토스 웹페이지에는 가격이 안 나와서 가격만 직접 적어야 해요.)
3. **Create**를 누르면 1~2분 안에 상품마다 글과 이미지 카드가 만들어지고, 비어 있는 시간대(08:30 · 12:30 · 20:30)에 `초안` 이슈가 생겨요.
   상품 사진, 평점, 리뷰 수, 순위는 링크에서 자동으로 가져와요.
4. 초안을 훑어보고 그 `상품` 이슈에 **`승인`** 댓글을 달면 모두 `예약`으로 바뀌어요.
   - 고칠 게 있으면 초안 이슈 본문을 고치고, 빼고 싶은 상품은 초안 이슈를 닫아요.
   - 확인 없이 바로 예약하려면 제목을 `상품 바로예약`으로 써요.
5. 예약 시각이 지나면 올라가요. GitHub 사정으로 **1~3시간 늦을 수 있어요.** 결과는 각 이슈 댓글로 남아요.

글을 하나만 직접 만들고 싶을 때는 글 도구(https://claude.ai/artifact/56kjPC8JU4j546Z1gphCqx)의 **③ 예약 보내기**도 쓸 수 있어요.

| 제목 | 동작 |
|---|---|
| `예약 10/23 09:00 계란` | 한국 시간 10월 23일 9시가 지나면 게시 |
| `예약 지금 계란` | 바로 게시 |
| `초안 10/23 09:00 계란` | 게시 안 함. `예약`으로 바꾸면 승인 |
| `실패 예약 …` | 실패한 글. 이유는 댓글에 있어요. 고친 뒤 `실패 `를 지우면 다시 시도 |

- 한 번에 최대 3개까지만 올려요. 나머지는 다음 확인 때 이어서 올려요.
- 글은 500자까지예요.
- 이미지는 PNG나 JPG 1장만 써요.

## 토큰 유효 기간
토큰은 보통 **60일** 동안 유효해요. 만료되면 게시가 실패하고 이슈에 "토큰이 만료됐어요" 댓글이 달려요.
그때 5단계를 다시 해서 새 토큰으로 `THREADS_ACCESS_TOKEN`을 바꿔 주세요.
