# 글감 창고

사용자가 "아이디어", "뭐 올리지", "글감"을 물어보면 이 파일을 보고 지금 계절·날짜에 맞는 것을 골라 제안한다.
레퍼런스 이미지·문장은 그대로 퍼 오지 않는다(출처 요청 있음). 방법과 주제만 쓴다.

## 방법: "사람들이 묻는 말"을 첫 줄로 (2026-10-29, 레퍼런스 @my.honeypick "오늘의 블로그 글감 50")
- 주제를 고르면 카페 글·지식iN·쇼핑몰 상품 문의에서 사람들이 실제로 묻는 질문을 뽑는다.
  예) 온수매트 물 보충 → "온수매트에 정수기 물 넣어도 됨?" "물은 어디까지 채워야 함?"
- 그 질문을 **글 첫 줄(킥)**로, 답 1~2줄 → 관련 상품 링크로 잇는다. 질문형 첫 줄은 "나도 궁금했음" 댓글이 붙기 쉽다.
- 답은 **설명서·제조사 안내 같은 확인된 사실만**. 모르면 "설명서에 적힌 물 종류부터 보기"처럼 확인 방법을 알려 준다(지어내지 않기).
- 스레드 예시:
  ```
  온수매트에 정수기 물 넣어도 됨?
  설명서마다 달라서 물 종류부터 봐야 됨
  (확인된 내용 한 줄)

  온수매트 전용 보충수 1L 3,900원
  링크는 댓글에 둠
  #광고
  ```
